凝恩语言

让中文成为编程的一等公民

凝恩语言（NINGEN）是一门全中文自然语言级编程语言，含全自研编译器、字节码 VM 与 ARM64 工具链，安全主权架构，不依赖任何开源编译框架，纯原生打造。

核心特性

中文一等公民

关键字、语法、错误提示全中文，自然语言级表达，让中文开发者零门槛上手。

安全主权架构

可证、唯一可验、安全可证明、衍生可溯源，安全从语言层面开始。

全自研工具链

编译器、汇编器、VM/JIT、签名工具全部自研，不依赖任何开源编译框架。

ARM64 原生

面向 ARM64 架构深度优化，配套中文汇编器，从底层掌握每一行指令。

全自研工具链

  • 凝恩编译器 — 全中文自然语言级编译前端，让代码像说话一样书写
  • ngas 中文汇编器 — 中文指令集汇编器，用中文书写汇编
  • m0 / m1 / m2 汇编器 — 多级汇编体系，逐层掌控机器细节
  • 字节码 VM / JIT — 自研虚拟机与即时编译引擎
  • NGX2 保护容器 — 代码保护容器，守护核心逻辑
  • ngkey 签名工具 — 签名与验证体系，衍生可溯源

开源与署名

开源协议：Apache-2.0

本仓库以 Apache-2.0 协议开源，并附加强制署名条款（详见仓库 NOTICE.md）：衍生作品必须标注「基于凝恩语言（NINGEN）」，禁止冒充。安全核心（NGX2 保护容器、ngkey 签名工具、验真/变异算法）保留闭源。
